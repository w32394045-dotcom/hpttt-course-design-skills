# 《反馈面谈》课程设计方案（新晋经理 · 半天 · 20 人）

**【草案 · 目标待确认】**

> 假设行：以下产出基于假设学习目标写成——「学员是刚带团队 0–12 个月的新晋经理，此前没受过反馈面谈训练，公司希望他们能自己处理下属的行为/绩效问题，而不是把矛盾上交或憋着不谈」。你确认（或改写）目标后，全篇才可改称【定稿】。

---

## ① 一句话学习目标

> **在下属出现行为偏差或绩效不达标时，独立完成一次结构化反馈面谈，并让下属带着自己认可的具体改进行动离开，成为一名靠反馈带人的新晋经理。**

- 工作行为：准备事实 → 开启面谈 → 说清问题 → 共创方案 → 定下行动
- 角色：靠反馈带人的新晋经理
- 无"了解 / 理解 / 掌握知识"类纯认知动词 ✔

**MECE 三查**

- **穷尽**：已按"为什么谈 → 谈前准备 → 怎么说 → 怎么听/共创 → 怎么定 → 谈崩了怎么办 → 谈完怎么跟"全链条追问过"还有吗"，补入第 16、17 两条。无明显遗漏。
- **独立**：按"谈前 / 谈中 / 谈后"与"说 / 听 / 定"切边界；原可拆的"引导自评""提问倾听"已合并进第 13 条，避免同一内容被重复计分。
- **衔接**：1–4 认知（为什么）→ 5–7 谈前 → 8–11 工具（怎么说/怎么听）→ 12–14 面谈三段 → 15–16 阻力 → 17 闭环，是一条可讲通的时间逻辑。

## ④ 课程模型

### 选择地图诊断（四个问题逐一作答）

| 诊断问题 | 答案 |
|---|---|
| 内容有先后 / 时间 / 操作顺序吗？ | **有。** 面谈天然是"准备 → 开场 → 对话 → 收尾"的时间线 → 命中 **②流程步骤式** |
| 要点间是层级或部分-整体关系吗？能找到一句话统摄的顶层吗？ | 部分有（"说 / 听 / 共"从属于"谈"），但顶层本身就是时间线，用金字塔反而绕 → 列为备选 |
| 要素间存在运算 / 因果（A×B=C）吗？ | **无。** 不存在"反馈 = A × B"式关系 → 排除 ④公式式 |
| 以上都不明显，是一组并列要点吗？ | **否。** 四拍有强先后，且"走音处理"依附于流程 → 排除 ①字母式 |

- **主选**：**②流程步骤式**——贴合操作、可直接逐拍示范演练，课堂推进节奏自然。
- **备选**：**③金字塔式**——若学员层级感混乱、需要先建立"面谈是一件事而不是四件事"的统摄认识，可用顶层"一次有效的反馈面谈"，下挂四拍。理由：更适合建立认知，但不如流程式好练。
- 字母式被否的说明：四拍首字"备启谈定"拼不成有意义的中文词；硬凑缩写比没有结构更糟。

### 模型：**「四拍面谈法」，英文记作 BEAT**

> 记忆钩子：面谈像打拍子，**四拍踩准，节奏就稳；走音了，先回到主旋律**。

```
        ┌───────────────────  四拍面谈法（BEAT） ───────────────────┐
        │                                                          │
 第1拍  │  B · Before  备 —— 只带事实，不带脾气                    │
  备    │      · 备证据：具体事例 / 数据 / 时间线（不用"你总是"）    │
        │      · 备目的：这次只谈哪一个行为（一次只拍一个音）        │
        ├──────────────────────────────────────────────────────────┤
 第2拍  │  E · Explain 启 —— 先给安全，再说目的                    │
  启    │      · 私下、约一间不被打断的会议室                       │
        │      · 开场句："我想和你聊一件具体的事，因为我在意你做得更好"│
        ├──────────────────────────────────────────────────────────┤
 第3拍  │  A · Ask     谈 —— 说行为、听想法、共定方案               │
  谈    │      说：SBI（情境—行为—影响）                           │
        │      铁律：说行为，不贴标签                              │
        │      共：先问"你自己怎么看"→ 下属先说方案，经理再补       │
        ├──────────────────────────────────────────────────────────┤
 第4拍  │  T · Target  定 —— 定行动、定跟进                        │
  定    │      · 谁 / 做什么 / 何时 / 达到什么标准                  │
        │      · 约好下次 1:1 回顾时间，当场写下来                  │
        └──────────────────────────────────────────────────────────┘
  走音处理（贯穿第3、4拍）：
     否认 / 辩解 / 沉默 → 不辩论，回到事实与影响
     哭泣 / 发火        → 先接住情绪（停 3 秒、递水、承认感受），再回到目的
     持续不达标        → 说清后果与改进边界（对齐公司制度）
```

### 逐要素目标校验

| 模型要素 | 是否锚定学习目标 | 处置 |
|---|---|---|
| 第1拍 备（证据） | 是——无事实则 SBI 无素材，谈必变情绪对抗 | 保留 |
| 第2拍 启（安全+目的） | 是——下属是否开口共创，取决于开场 30 秒 | 保留 |
| 第3拍·说（SBI） | 是——直接兑现"结构化反馈面谈" | 保留 |
| 第3拍·铁律（行为不贴标签） | 是——贴标签触发防御，行动无从谈起 | 保留 |
| 第3拍·共（自评+共创） | 是——直接兑现"自己认可的具体改进行动" | 保留 |
| 第4拍 定（行动+跟进） | 是——兑现目标末端"带着行动离开" | 保留 |
| 走音处理 | 是——兑现"独立完成"（现场没有人在旁边救场） | 保留 |
| 绩效不达标后果澄清 | 是——够用且必要，但要与公司制度对齐 | 保留（见待确认清单） |

- **整体结论：学员理解这个模型不需要任何额外背景知识。** 唯一需要讲清的只有 SBI 三个字母，课堂 3 分钟即可落地；不需要先学任何外部理论。
- **教学可行性终检**：好记（四拍 + BEAT 双关）✔ / 好讲（可逐拍示范、逐拍演练）✔ / 课后好复制（学员可自评"我今天踩到第几拍"）✔

## ⑤ 课程名候选（4 个）

**主题类型判断**：新晋经理对"给下属提意见"有明确痛点——开不了口、一谈就崩、谈完没动静 → 主选 **痛点式**。

| # | 候选课名 | 抓的是哪一点 | 名实一致 | 吸引眼球 |
|---|---|---|---|---|
| 1 | **《别再憋着不谈：新晋经理的四拍反馈面谈》** | 痛点（逃避、拖延）+ 模型名 | 课程就是练"怎么谈"，四拍即模型，兑现得了 | "憋着不谈"具体、有画面 |
| 2 | **《反馈不翻车：新晋经理面谈四拍法》** | 痛点（一谈就崩） | 全程演练"不翻车"的四个动作，承诺不夸大 | "翻车"是高共鸣词 |
| 3 | **《谈完就有人动：新晋经理反馈面谈实练》** | 利益（结果具象） | 收尾共识那拍直接产出"谁做什么何时" | "有人动"把结果画面化 |
| 4 | **《把难听的话，说进心里去：反馈面谈工作坊》** | 痛点 + 焦点（画面感） | 课程确实教"怎么说事实"让人接受 | 反差句式有情绪张力 |

> 命名与目标一致性终检：4 个候选承诺的都是"能独立谈、谈得下去、谈完有行动"，与第 1 步学习目标同向，无漂移。**最终选哪个由你定，我不替你拍板。**
