【草案 · 目标待确认】

> 本稿采用假设：目标学员为晋升 0–6 个月、带 3–10 人团队的基层经理（多为技术/业务骨干转管理）；核心痛点是"不敢谈、一谈就崩"；课时半天（3.5 小时，含 15 分钟茶歇）；现场 20 人可分组。学习目标未经你确认，故全稿为草案。

---

## ① 一句话学习目标

> **面对下属出现绩效偏差或需要纠偏的行为时，新晋经理能在一次 15 分钟的一对一面谈中，独立走完"备事实—说影响—听真话—定行动"四步，并当场与下属达成下一步行动共识，成为让下属愿意说真话、敢说真话的团队负责人。**

（含明确工作行为 + 角色；未使用"了解／理解／掌握"类纯认知动词。）

## ② MECE 知识点清单（18 条）

**A 认知与准备**
| 编号 | 知识点 |
|---|---|
| K01 | 反馈的类型与目的：正向反馈 vs 建设性反馈的区分与使用时机 |
| K02 | 面谈前设定目标：这次谈话希望对方改变什么行为或结果（一句话目标） |
| K03 | 事实与判断分离：把"我觉得你不行"翻译成可观察行为 |
| K04 | 证据准备：具体时间、场景、数据、影响链（行为→结果） |
| K05 | 面谈时机选择：即时反馈与预约面谈的边界 |
| K06 | 面谈前自我校准：情绪与动机自检（帮他成长 vs 出气） |

**B 对话过程**
| 编号 | 知识点 |
|---|---|
| K07 | 开场 30 秒：说清目的、划定边界、建立安全 |
| K08 | 面谈六步结构：准备—开场—陈述—倾听—共识—收尾 |
| K09 | 陈述事实的表达法：中立描述 + 影响说明 |
| K10 | 倾听与提问：开放提问、复述确认、让对方先讲 |
| K11 | 防御与情绪应对：沉默／反驳／甩锅／哭泣的现场处理 |
| K12 | 对事不对人：反馈行为，不给人格贴标签 |

**C 收尾、场景与风险**
| 编号 | 知识点 |
|---|---|
| K13 | 共识与行动：谁做什么、何时、如何验证（下一步行动化） |
| K14 | 跟进闭环：约定复盘时间，验证行为是否改变 |
| K15 | 双向反馈：邀请下属对经理本人提反馈 |
| K16 | 高难场景：老员工／绩效差／明星员工翻车／跨代际偏好 |
| K17 | 记录与留痕：面谈记录与绩效证据管理 |
| K18 | 常见误区：三明治法、公开批评、翻旧账、只给结论 |

**MECE 三查结论**：穷尽——覆盖"准备→对话→收尾→场景→风险"全链，已用"还有吗"追问补入 K15／K17；独立——K01 与 K18 分属"类型"与"错误"，K03 与 K12 已合并归位（见打分表说明），无交叉计分；衔接——A→B→C 与真实面谈时序一致。

## ④ 课程模型

### 选择地图诊断结论

| 诊断问题 | 答案 | 指向 |
|---|---|---|
| 有先后/时间/操作顺序吗？ | **有**——面谈是固定时序：先说事实、再听、后定行动，顺序不可对调 | ② 流程步骤式 |
| 要点间有层级/部分-整体关系吗？ | 弱——有一句话可统摄（"让对方愿意说真话"），但向下分层不明显 | ③ 金字塔式 |
| 要素间有运算/因果关系吗？ | 无——不存在 A×B=C 的关系 | 不适用 |
| 是一组并列要点吗？ | 否——四步有强顺序 | 不适用 |

- **主选：② 流程步骤式。** 理由：内容本身就是一次对话的时间线，流程式与学员课后的真实使用场景完全同构，无需转化。
- **备选：③ 金字塔式。** 理由：先用一句话顶层统摄（"让人愿意说真话"）再向下分四步，讲课时更省时间、更适合基础参差的班；但记忆钩子弱于流程式。若现场学员管理经验差异大，可切备选。

### 模型：反馈面谈「四步环」

> **备事实 → 说影响 → 听真话 → 定行动**

| 步骤 | 一句话动作 | 承载的关键知识点 |
|---|---|---|
| **备事实** | 定这次要改变什么，把手上的"看法"换成能看见的事实 | K03（+ 课前 K02、K04 承接） |
| **说影响** | 中立说事实，紧接着说这件事对团队/客户/他本人的影响 | K09 |
| **听真话** | 先问先听，接住沉默、反驳和情绪，把话问出来 | K10、K11 |
| **定行动** | 一起定下一步：谁、做什么、何时、怎么验证 | K13 |
| （骨架） | 四步来自面谈的固定结构，走完一轮即闭环，下次从"备事实"再入环 | K08 |

### 目标校验（逐要素）

| 要素 | 是否锚定学习目标 | 保留/删除 |
|---|---|---|
| 备事实 | 是——没有事实，"说影响"会退化成人身攻击，目标第一步就断 | 保留 |
| 说影响 | 是——对应目标的"说清事实—讲清影响"直接动作 | 保留 |
| 听真话 | 是——目标要求"下属愿意说真话"，只能靠听出来 | 保留 |
| 定行动 | 是——目标明确含"当场达成下一步行动共识" | 保留 |

- **是否有凑形式要素**：否，四步逐一锚定目标，无形式需要项。
- **学员理解模型是否需要额外背景知识**：**否**。四个词都是日常管理口语，不需要任何前置理论或模型基础，零管理背景的学员也能一次听懂。

### 教学可行性终检

| 检查项 | 结论 |
|---|---|
| 学员好记吗 | 是——四步全是动作动词、顺序与真实对话一致，课上一张图，课后不看讲义可复述 |
| 讲师好讲吗 | 是——四步可直接展开成"讲 5 分钟 + 练 8 分钟 ×4 轮"的同一模板 |
| 课后好复制吗 | 是——每步配一张卡（目标卡／事实卡／提问卡／行动卡），照卡就能再谈一次 |

## ⑤ 课程名候选（3–5 个）

**命名时机检查**：学习目标可一句话说出 ✔｜关键知识点已选定（6 个）✔｜课程结构/模型已定 ✔ → 具备命名条件。
**主题类型**：**痛点式**（新经理对反馈有明确且尖锐的痛：怕得罪人、怕谈崩、怕对方离职）。

| # | 候选课名 | 抓的是哪一点 |
|---|---|---|
| 1 | 《别等员工辞职才谈：新经理的反馈面谈四步环》 | 痛点式 · 戳中"好员工悄悄走" |
| 2 | 《把"你不行"说成"你能行"：新经理反馈面谈实战》 | 痛点式 · 前后落差，暗示改变 |
| 3 | 《开口不翻脸：新经理 15 分钟反馈面谈》 | 痛点式 + 利益点 · 给时间承诺 |
| 4 | 《从憋着到说透：反馈面谈四步环》 | 痛点式 · 描述症状到解法 |
| 5 | 《新经理第一课：一场 15 分钟的反馈面谈》 | 焦点式 · 直给场景与时长 |

**两条检验**
- **名实一致**：5 个候选承诺的"四步／15 分钟／开口不翻脸"课程均可兑现（现场含真实案例角色扮演与行动共识演练），无"名字大于内容"。
- **吸引眼球**：候选 1、2 最强（有具体痛处与反差）；候选 3 兼顾招生与时长承诺；候选 5 最稳妥，适合内部强制参加场景。

## 课程时间表（半天 = 210 分钟，含茶歇 15 分钟）

| 时段 | 内容 | 时长 |
|---|---|---|
| 开场 | 痛点投票："你上一次想跟下属谈却没谈，卡在哪？" + 靶心对齐 | 15' |
| 全景 | 模型亮相：四步环一张图 + 一段 3 分钟反面示范视频 | 15' |
| 模块一 | **备事实**（K03）：把评价翻译成行为的改写练习（个人 + 小组互改） | 25' |
| 模块二 | **说影响**（K09）：中立陈述 + 影响链话术，两人对练 + 讲师示范 | 30' |
| — | **茶歇** | 15' |
| 模块三 | **听真话**（K10 + K11）：提问卡演练 + 情绪/沉默四种情景应对 | 40' |
| 模块四 | **定行动**（K13）：把对话收口成"谁·做什么·何时·怎么验证" | 25' |
| 综合演练 | 5 组 × 4 人，真实案例角色扮演（说／听／观察三顶帽子轮换）+ 互评 | 35' |
| 收尾 | 个人行动承诺（本周要谈的那一个人）+ 30 天跟进说明 | 10' |
| | **合计** | **210'** |

**20 人分组安排**：5 组 × 4 人；每组内"当事人／经理／观察员／记录员"四顶帽子轮换，保证每人至少当一次经理；会前 3 天收集每人 1 个真实下属问题，作为综合演练素材。
