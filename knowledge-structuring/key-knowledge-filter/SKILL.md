# 关键知识点筛选法

## 交付物

三样一起交：① **已填满的三指标打分表**（含总分列与名次列）② 被砍清单及逐条理由 ③ ≤8 个关键知识点结论。

只给表头模板、只讲打分方法、只承诺"接下来会打分"，都算未完成。

## 完成判据（交稿前逐条核对）

- [ ] 表里每一行都填了重要性 / 难度 / 频率三个排序分，无空单元格、无占位符
- [ ] 三个指标的排序方向统一（例如统一"数字大 = 更重要 / 更难 / 更频繁"）
- [ ] 有总分列与名次列，按总分降序排列
- [ ] 权重已与用户确认（默认 重要性×3、难度×3、频率×1）
- [ ] 被砍清单逐条给理由（打分表就是和业务方对齐的证据）
- [ ] 最终结论 ≤8 个关键知识点

## 执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **检查罗列质量（MECE 三要求）**
   - 拿到用户的知识点清单，逐条核对：穷尽（有明显遗漏吗？可用"还有吗"追问 + 建议邀请明星员工补盲）/ 独立（有交叉重叠吗？合并）/ 衔接（关系清楚吗？）
   - 若用户还没有清单：先引导穷尽罗列，此步禁止筛选
   - 完成标准: 清单通过三要求检查
   - 判停条件: 若内容是**流程类知识点**（操作步骤不可更改），跳过第 3 步直接按流程组织；若是**固化知识点**（如法规），仍走完整筛选，未选中的用读书打卡等混合式学习落地

2. **校准颗粒度**
   - 问清课程时长，判断当前颗粒度是否匹配（半天→大颗粒；1-2 天→细颗粒）
   - 颗粒度不可变而时间不够时：执行"少就是多"，只保留最重要的颗粒
   - 自检金句："这些内容是学员需要的，还是你认为他们需要的？"
   - 完成标准: 清单颗粒度与课时匹配

3. **三指标单项排序打分** 🔴 CHECKPOINT
   - 造表：列 = 知识点 / 重要性 / 难度 / 频率；对每个指标单独做 1-N 排序（N=知识点数）
   - 三指标排序方向必须统一（如统一"数字大=更重要/更难/更频繁"）
   - 与用户确认权重（默认 重要性×3、难度×3、频率×1；频率不重要时调低）—— 🔴 权重须用户点头
   - 完成标准: **表里每一行都填了 3 个分数**（不允许出现空单元格、占位符或只给表头模板），且用户认可排序依据
   - 注意: 难度 = 内容间相对难度（不代入"小张觉得难"）；频率 = 时段内执行次数（不代入"几个人做"）

4. **加权汇总并截取** 🔴 CHECKPOINT · 被砍清单须用户过目
   - 计算总分 = Σ(排序分 × 权重)，按总分降序，取 Top 6（最多 8）
   - 向用户展示被砍掉的清单及理由（打分表就是和业务方沟通的证据）—— 🔴 显式写出"砍了什么、为什么"，才算收敛完成
   - 完成标准: 交付物里同时有 ①**已填满的打分表**（含总分与名次列）②被砍清单及逐条理由 ③≤8 个关键知识点结论。只有表头模板或只有方法说明，都算未完成
   - 下一步: 调用 `knowledge-modeling` 把选出的点串成模型

### 异常 fallback 速查 (if X 失败 → Y)

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 学习目标还没定 | 回 `plan-course-4-steps` 第 1 步定目标（重要性锚在目标上，无目标则打分无锚） | 用"二选一"式追问帮用户收敛；仍定不下就**不做筛选**，先只出 MECE 清单 |
| 用户不肯给课时（"先筛出来再说"） | 说明颗粒度与课时强相关，没课时无法校准 | 先按"最大颗粒"筛一版，并在结果上标注"课时未定，颗粒度待复校" |
| 清单没过 MECE（大量交叉重叠） | 先合并重叠项，再进打分 | 回罗列步骤重来；**禁止带着重叠项打分**（重叠会让同一内容被多次计分） |
| 业务方坚持"全都要讲" | 用打分表当对齐证据，展示被砍清单及理由 | 让步方案：把未入选项转为**课后混合式学习**（读书打卡/自学材料），而不是硬挤进课堂 |
| 发现三指标排序方向被搞反 | 立即停下，统一方向（如统一"数字大 = 更重要 / 更难 / 更频繁"） | 全部推倒重排，不做局部修补（局部修补必然汇总错乱） |
| 内容是流程类知识点（操作步骤不可更改） | 跳过第 3、4 步，直接按流程顺序组织 | 转去用教学设计方法解决"怎么讲"，不要在本 skill 里强行打分 |
| 内容是固化知识点（法规/制度） | 仍走完整筛选，未选中的用课后学习落地 | 与业务方确认合规底线：必考项不能因分数低被砍 |

## 什么时候不要用这个 skill

- **知识点清单还不存在** — 先罗列（plan-course-4-steps 第 2 步），没有池子无从筛选
- **流程类不可拆内容** — 作者明确：流程类知识点无法更改时跳过筛选，直接按流程讲
- **学习目标还没定** — 重要性 = 对绩效（目标）的影响；目标未定，打分无锚。先定目标
