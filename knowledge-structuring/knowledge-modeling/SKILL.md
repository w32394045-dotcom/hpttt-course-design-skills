# 知识点结构化 / 模型化

## R — 原文 (Reading)

> "将知识点结构化或模型化，不仅方便学员记忆，而且方便培训师讲授……GAPS的英文原意是'差距'，与绩效改进的核心观点——寻找关键差距的意义完全吻合，这样的结构化和逻辑化容易让学员记住并应用。"
>
> — 王志刚, 第七章「计划课程四步骤·第三步」

---

## I — 方法论骨架 (Interpretation)

把零散知识点凝练成一个**可命名的模型**，让记忆自然发生、讲授有主线。四种方式，按内容特性选择：

| 方式 | 适用内容特性 | 经典例子 | 关键动作 |
|---|---|---|---|
| **① 字母结构化** | 一组**并列**要点 (3-6 个)，无先后、无层级 | SMART、GAPS、销售 HAND 法则 | 找到能统摄要点的英文缩写，且缩写本身要有**意义钩子** (GAPS=差距, HAND=助手, SMART=聪明) |
| **② 流程步骤结构化** | 内容有天然**时间轴/操作顺序** | 培训管理四步曲、成人教学设计八段锦 | 按时间或操作先后排成步骤链，符合人脑记忆逻辑 |
| **③ 内容逻辑结构化 (金字塔)** | 要点间有**层级/统摄关系**，顶层能一句话说清 | 高效能人士的七个习惯、导师罗盘 | 搭金字塔：顶层逻辑极简，层层深入；要点间的关系 (如 依赖→独立→互赖) 要在模型中可见 |
| **④ 公式结构化** | 要素间存在**运算/因果关系** | 绩效 = 有价值的结果 / 行为；超越五星客服 = 人 + 流程 | 用加减乘除表达要素关系，把复杂定义清晰化 |

**两条铁律：**
1. **意义钩子**：模型的名字本身要承载意义并与主题吻合，让人"记住词就记住内容"
2. **目标校验**：结构化必须锚定课程目标——模型中每个要素都要对目标有贡献；形式再精妙，脱离目标就是花架子

## A1 — 书中的应用 (Past Application)

### 案例 1: 销售 HAND 法则 (字母式)
- **问题**: 新入职销售人员培训课程用了两年，话术太多像 Q&A、无规律、记忆难；新人一个月才能胜任，月内离职率 50%
- **方法论的使用**: 作者不直接给方案，而是追问"关键知识点都跟谁相关？对客户有分类吗？能不能结构化？"学员把话术按客户表情重构：H 憎恶 / A 积极 / N 木讷 / D 对应方式——HAND 恰有"助手"之意 (意义钩子)
- **结论**: 并列的话术按"客户表情"分类后获得结构，无效话术被自然淘汰
- **结果**: 课程从 3 天压到 1 天，新人快速胜任，月内离职率降到 20% 以内

### 案例 2: 导师罗盘 (金字塔式)
- **问题**: 绩效改进项目要降低某公司员工流失率，根因分析发现导师带教是关键解决方案
- **方法论的使用**: 萃取内部经验发现关键内容，用内容逻辑结构化成"导师罗盘"模型，形成版权课程
- **结论**: 经验只有被结构化后才能复制、才能成为知识资产
- **结果**: 当年该公司员工流失率环比下降 20% 以上

### 案例 3: 五行修心路 → 超越五星客服 = 人 + 流程 (公式式, 反例转正)
- **问题**: 客服团队把课程包装成"客服五行修心路"，用五行学说对应五个要点，看似博大精深
- **方法论的使用**: 作者用课程目标校验：木对应传、水对应润……学员理解不了，且关于五行的讨论与课程目标、课后应用毫无关系——形式脱离了目标。团队重新梳理后改用公式结构：超越五星客服 = 人 + 流程
- **结论**: 两大模块 (与人相关/与工作相关) 一清二楚，操作性大增
- **结果**: 课程逻辑瞬间清晰——这是"结构化必须锚定目标"最经典的反面教材

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 工作坊中，学员已选出 5-6 个关键知识点，摆在桌上却"串不起来"，没有主线
2. 课程内容本身不错，但学员反映"记不住""像 Q&A""没有规律"
3. 想模仿 SMART / GAPS / 七个习惯那样，把自己的方法论包装成可传播的模型
4. 经验萃取项目收尾，需要把萃取出的关键内容固化为可复制的课程结构

### 语言信号 (用户的话里出现这些就应激活)

- "这些知识点怎么串起来 / 怎么组织成模型"
- "怎么让学员记得住 / 好记一点"
- "帮我像 SMART 那样包装一下"
- "课程没有主线 / 没有结构"
- "structure / model / framework / 结构化 / 模型化 / 口诀"

### 与相邻 skill 的区分

- 与 `key-knowledge-filter` 的区别: filter 负责"选出哪些点"（收敛，做减法）；本 skill 负责"把选出的点组织成模型"（结构化，做整合）。先筛选，后建模
- 与 `course-title-naming` 的区别: 本 skill 给**内容**造结构（模型名如 HAND 是内容结构的副产物）；naming 给**整门课**起名（营销视角的三点式）
- 与 `plan-course-4-steps` 的区别: 本 skill 是四步骤第 3 步后半段的深挖；没有完整流程概念时先用 plan-course-4-steps

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点输入** 🔴 CHECKPOINT（前置校验，不过不建模）
   - 确认知识点已完成筛选（≤8 个关键知识点）；若还是十几个未筛的点，先调用 `key-knowledge-filter`
   - 确认课程学习目标可一句话说出（结构化要锚定的靶子）；说不清先回到 `plan-course-4-steps` 第 1 步
   - 🔴 判停: 知识点 >8 个未筛 / 学习目标说不出 → 停止建模，回对应前置 skill
   - 完成标准: 手头有"≤8 个关键知识点 + 一句学习目标"

2. **诊断内容特性（选择地图）**
   - 依次问四个问题，定位 1-2 种候选方式：
     - 内容有**先后/时间/操作顺序**吗？ → 有 → ② 流程步骤式
     - 要点间是**层级或部分-整体**关系吗？能找到一句话统摄全局的顶层吗？ → 能 → ③ 金字塔式
     - 要素间存在**运算/因果**关系（A 与 B 相乘/相加/相比得到结果）吗？ → 有 → ④ 公式式
     - 以上都不明显，是一组**并列**要点？ → ① 字母式
   - 完成标准: 明确 1 个主选方式 (+1 个备选)，并能说出"为什么是这种"

3. **构造模型初稿**
   - 按所选方式构造：
     - 字母式: 提炼各要点的核心词 → 找能拼成**有意义单词**的字母组合 → 词义必须与主题吻合 (钩子)
     - 流程式: 按时间/操作顺序排链 → 每步命名 → 检查链条无断点
     - 金字塔式: 先写顶层一句话 → 向下分层 → 标出层间关系 (递进/并列/因果)
     - 公式式: 确定结果变量 → 拆解构成要素 → 确定运算关系 (+ − × ÷)
   - 完成标准: 模型可画出/写出，且有一个**可命名的名字**

4. **目标校验 (铁律) 🛑 STOP · 不过则回炉**
   - 逐要素问："这个要点对学习目标有贡献吗？没有它是形式需要还是内容需要？"
   - 整体问："学员理解这个模型需要额外背景知识吗？"（五行修心路就死在这问）
   - 🛑 判停条件: 任何要素是"为了凑形式"而存在 → 删要素或换方式，回到第 2 步；模型需要学员先学另一套知识才能懂 → 放弃该形式
   - 完成标准: 每个要素都锚定目标，模型对目标学员"零额外背景可懂"

5. **教学可行性终检**
   - 三问：学员好记吗（有意义钩子/顶层极简）？讲师好讲吗（结构能展开成教学流程）？课后好复制吗（离开课堂还能用）？
   - 完成标准: 三问皆"是"，模型定稿

### 异常 fallback 速查 (if X 失败 → Y)

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 输入盘点: 知识点 >8 个未筛 | 回 `key-knowledge-filter` 收敛 | 本轮只做 MECE 罗列，建模改期 |
| 学习目标一句话说不出 | 回 `plan-course-4-steps` 第 1 步 | 用"健康还是漂亮"式二选一帮用户收敛 |
| 字母式找不到有意义的单词 | 换流程式或金字塔式 | 放弃缩写，用直白步骤链命名 |
| 目标校验发现凑形式要素 | 删该要素或换结构化方式 | 放弃当前模型，回知识点清单重诊 |
| 模型需学员先学额外背景 (五行类) | 换零背景形式 (流程/公式) | 沿用知识点清单直讲，不强行模型化 |
| 四种方式都套不上 | 降级为"弱结构" (编号清单+逻辑分组) | 结构化不是必选项，内容有效优先 |

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **知识点还没筛选** — 给 15 个点建模等于给混乱打包；先收敛到 ≤8 个
- **学习目标未定** — 模型是目标的表达形式，没有靶子的结构化必然沦为形式游戏
- **内容本身是单一连续流程且不可改** — 直接按流程讲即可，不必为了"有个模型"而造模型
- **追求传播噱头超过教学效果时** — 模型是记忆工具不是营销包装（营销包装是 course-title-naming 的事）

### 作者在书中警告的失败模式

- 🛑 **结构化脱离课程目标（头号陷阱）**: 五行修心路——形式博大精深，但学员理解不了对应关系，关于五行的讨论与课程目标、课后应用毫无关系。**形式感越强，越要做目标校验**
- **无结构的堆叠**: 销售旧课程的话术 Q&A——内容全都在，但没有结构，记忆负担压垮学员，新人离职率 50%
- **为凑字母而牵强**: 意义钩子的前提是"词义与主题吻合"；生拼硬凑的缩写比没有结构更糟（此条为作者"吻合"要求的反向推论，工作坊高发）

### 作者的盲点 / 时代局限

- **四种方式的选择标准书里没有显式化** — 书中靠案例暗示"跟内容特性走"，本 skill 第 2 步的"选择地图"是蒸馏时从案例中提炼的增补，使用中应鼓励用户双方案对比而非死守单一方式
- **分类未必完备** — 矩阵式 (2×2)、循环式在书中案例里实际出现却未单列 (七个习惯图实为循环+层级混合)；四种方式是脚手架不是牢笼
- **AI 可协助头脑风暴缩写词与模型名**，但"意义钩子与主题是否吻合"必须人判断

### 容易混淆的邻近方法论

- **视觉化排版/图示设计**: 把文字画成图 ≠ 结构化；结构化改变的是内容的组织逻辑，不是呈现样式
- **思维导图**: 是发散工具；模型化是收敛工具——思维导图常在罗列阶段用，模型化在收敛后用
- **课程命名 (course-title-naming)**: 模型名服务记忆与讲授，课程名服务吸引与传播，两套标准
