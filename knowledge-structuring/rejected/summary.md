## U8 — 固化/流程类知识点处理 (V1 不通过)

- **出处**: 第七章·第二步"罗列知识点"末尾小节
- **内容**: 固化知识点 (如法律法规) 建议完整走四步骤+混合式学习落地; 流程类知识点不可更改, 跳过"选关键"步骤
- **不通过项**: V1 跨域验证——全书仅在本章此小节出现一次, 无第二个独立语境佐证
- **处置**: 降级为 S2 (关键知识点筛选法) 的"边界/例外"段。内容有价值 (工作坊学员常问"我们法规课怎么办"), 但证据链不足以支撑独立 skill
- **捞回条件**: 若作者在《换种教法》其他章节或《绩效改进》系列书中有呼应论述, 可补足 V1 后独立

## U9 — 关注目标而非行为 (验证通过, 但不独立)

- **出处**: 第七章·底层逻辑第一节 (射击案例 + 减肥课学员案例)
- **三重验证**: V1 ✅ (射击/减肥课/批评课 3 个独立语境) V2 ✅ V3 ✅
- **不独立原因**: 体量不足——它是一条底层逻辑而非操作流程, 独立成 skill 会写成"只有态度没有步骤"的空心 skill
- **处置**: 作为 S1 (计划课程四步骤) 的"为什么"开篇, 也是 S2/S3 的灵魂约束 (三指标里的"重要性"=对目标的影响, 结构化的目标校验)

## U10 — 关注关键工作而非全部工作 / 快速胜任 (验证通过, 但不独立)

- **出处**: 第七章·底层逻辑第二节 (批评的沟通艺术案例 + 销售 4 年 vs 3 个月)
- **三重验证**: V1 ✅ V2 ✅ V3 ✅ ("快速胜任而非胜任"反直觉)
- **不独立原因**: 同 U9, 是价值标尺而非操作步骤
- **处置**: 并入 S1 底层逻辑章; "快速胜任"作为所有 skill 共用的价值检验标准 (这门课能让学员多快上岗?)
