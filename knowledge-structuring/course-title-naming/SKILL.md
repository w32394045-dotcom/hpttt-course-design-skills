# 课程主题命名三点式

## R — 原文 (Reading)

> "根据最终选择的关键知识点，给课程起一个好莱坞大片式的名称，以保证该名称足够吸引大家的眼球，激发大家的兴趣。这是最后要考虑的问题，而不是一开始要考虑的问题。因为经过这四个步骤的分析，最初那个课程主题已经面目全非，需要对其重新定位和思考。"
>
> — 王志刚, 第七章「计划课程四步骤·第四步」

---

## I — 方法论骨架 (Interpretation)

课程命名是课程设计的**最后一步**，不是第一步——走完定目标、列知识点、选关键、结构化之后，最初拍脑袋的主题往往已面目全非，需要重新定位。

好主题 = 好莱坞大片式名称，符合**三点式**之一：

1. **直击痛点** — 主题戳中学员工作/生活中的真实痛处。适用：痛点明确且普遍。例："一个小改变，孩子成学霸"
2. **找到焦点** — 痛点和利益点都不特别明确，但内容是日常重要工作，需要让学员对内容一目了然。适用：常规但重要的主题。例："数据会说话：数据分析与应用"
3. **切入利益点** — 直接勾住人的利益向往，最容易抓兴趣。适用：与学员收益强关联的主题。例："百万年薪：方法论铸就传奇"

判断顺序：先看有没有明确痛点 → 没有再看利益关联 → 都不突出就聚焦内容焦点。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 减肥课的主题改写
- **问题**: 学员初始主题是"30 天如何快速减肥"，看似吸引人
- **方法论的使用**: 作者追问课程目标——目标是"健康"和"保持体重"而非"减肥"；主题与目标错位（减肥主题会吸引错误期待、绑架错误内容）
- **结论**: 主题必须服从澄清后的学习目标，学员把主题改成了生活方式方向
- **结果**: 主题、目标、内容三者归位——这正是"命名是最后一步"的实证

### 案例 2: 三个三点式示范 (书中给出的范式)
- **痛点式**: "一个小改变，孩子成学霸"——戳家长"孩子不好好学习且没有好方法"的痛
- **焦点式**: "数据会说话：数据分析与应用"——痛点利益都不突出，让日常重要工作一目了然
- **利益式**: "百万年薪：方法论铸就传奇"——领导力课直接勾住利益向往

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 课程内容设计完成，进入包装/招生/发布环节，需要一个抓人的名字
2. 现有课程名平淡（"XX 培训""XX 基础课程"），想提升吸引力
3. 工作坊收尾，学员拿着刚设计好的课程问"老师，叫什么好？"

### 语言信号 (用户的话里出现这些就应激活)

- "帮我给课程起个名字 / 起个标题"
- "这个课叫什么好"
- "课程名太平了，帮我包装一下"
- "course title / naming / 课程命名"

### 与相邻 skill 的区分

- 与 `knowledge-modeling` 的区别: 模型名 (如 HAND 法则) 服务**记忆与讲授**，是内容结构的副产物；课程名服务**吸引与传播**，是营销动作。先造模型，后起课名
- 与 `plan-course-4-steps` 的区别: 本 skill 是四步骤的第 4 步独立成册；课程还没设计时直接用 plan-course-4-steps，禁止"先起名后设计"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认命名时机成熟**
   - 检查：学习目标可一句话说出？关键知识点已选定（≤8 个）？课程结构/模型已定？
   - 判停条件: 任一不满足 → 命名时机未到，引导回 `plan-course-4-steps` 对应步骤；**先起名会被名字绑架内容**
   - 完成标准: 三项检查全通过

2. **判断主题类型（三选一）**
   - 问："学员对这门课的内容，有明确的痛吗？" → 有 → 痛点式
   - 没有痛点，问："学好这个对学员的钱/晋升/业绩有直接好处吗？" → 有 → 利益式
   - 都不突出 → 焦点式（让内容一目了然）
   - 完成标准: 明确主选类型，并能说出依据

3. **按类型生成候选名 (3-5 个)**
   - 痛点式: 戳中具体痛处 + 暗示改变（"小改变 → 大结果"的反差尤佳）
   - 利益式: 利益具象化（数字、身份、结果）+ 方法暗示
   - 焦点式: 主标题给画面感（比喻/拟人）+ 副标题说清楚内容（"数据会说话：数据分析与应用"结构）
   - 完成标准: 每个候选都能说出"它抓的是哪一点"

4. **目标一致性终检**
   - 拿候选名对照学习目标：名字承诺的，课程能兑现吗？名字吸引来的人，是目标学员吗？
   - 好莱坞检验：够吸引眼球吗？能激发兴趣吗？
   - 判停条件: 名不副实（名字 > 内容）→ 降级夸张成分；名实不符（名字指向偏离目标）→ 回第 3 步
   - 完成标准: 定稿名称通过"名实一致 + 吸引眼球"双检验

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **课程内容还没设计** — 命名是最后一步；先起名会让内容被名字绑架（减肥课学员若不改主题，就会继续讲违背"健康"目标的内容）
- **内部例行培训且无需招生** — 三点式解决"吸引"问题；强制参加的合规培训，清晰大于吸引
- **给内容模型起名** — 模型名用意义钩子逻辑（knowledge-modeling），不是三点式

### 作者在书中警告的失败模式

- **一开始就定主题**: 作者明确这是"最后要考虑的问题，而不是一开始要考虑的问题"——先定名后设计，课程会被名字带偏
- **主题与目标错位**: 减肥课案例——主题承诺"减肥"，目标却是"健康/保持体重"，吸引来错误的期待，内容被迫跑偏

### 作者的盲点 / 时代局限

- **三点式只有正面范式没有检验标准**: 书中给了三个好例子，但"多夸张算过度"没有刻度——本 skill 第 4 步的"名实一致"检验是蒸馏时的增补，标题党风险需人把控
- **2019 年语境**: 短视频/信息流时代标题竞争更激烈，"好莱坞大片式"的阈值在提高，但"名实一致"原则反而更重要（翻车成本更高）

### 容易混淆的邻近方法论

- **爆款标题写作技巧 (新媒体)**: 面向文章流量，允许夸张甚至误导；课程命名必须名实一致——名字是课程目标的承诺
- **品牌命名**: 面向长期资产；课程命名面向单次传播与招生，可以更"大片化"
