```yaml
type: framework
source_units: [U6(四方式+意义钩子+目标校验)]
V1_cross_domain:
  passed: true
  evidence:
    - 字母式: SMART (经典) + GAPS (作者课程) + HAND 法则 (学员现场产出, 3 个独立语境)
    - 流程步骤式: 培训管理四步曲 + 八段锦/四步骤自身
    - 内容逻辑式: 七个习惯 (经典) + 导师罗盘 (作者项目, 流失率降 20%+)
    - 公式式: 吉尔伯特绩效公式 + 培训师成功公式 + 五行修心路改造 (超越五星客服=人+流程)
V2_predictive_power:
  passed: true
  novel_question: "学员筛选出 5 个关于'客户异议处理'的关键知识点, 彼此无时间顺序, 怎么串成模型?"
  derived_answer: "无时间顺序排除流程式; 要素间无运算关系排除公式式; 优先尝试按客户类型/表情分类后套字母式 (HAND 路径), 或用金字塔找顶层统摄逻辑 (导师罗盘路径); 全程用课程目标校验——串不起来说明知识点本身要回炉"
V3_exclusivity:
  passed: true
  why_not_common: "常识是'把内容做成图'; 作者的差异化: ① 模型要有意义钩子 (GAPS=差距, HAND=助手) ② 结构化必须锚定课程目标 (五行修心路反例) ③ 四种方式对应不同内容特性 (隐含选择逻辑, skill 中显式化)"
→ 进入阶段 2 (用户指定最高优先级)
```
